LO USADO EN LA MV-MS2-PRUEBA:

(Instrucciones para cuando haya IP de base de datos más abajo)


Después de subir la docker image a dockerhub (clona el repo nomás y pushea a tu dockerhub)
y hacerle pull en la MV, crear compose y .env:


nano docker-compose.yml    #pega el docker-compose de abajo
nano .env                  #pega el .env de abajo
docker compose pull
docker compose up -d
docker ps
curl http://IPPUBLICA-MV:8002/actuator/health


docker-compose.yml:

services:
  postgres:
    image: postgres:16
    container_name: ms2-postgres
    environment:
      POSTGRES_DB: ${DB_NAME}
      POSTGRES_USER: ${DB_USER}
      POSTGRES_PASSWORD: ${DB_PASSWORD}
    ports:
      - "5434:5432"
    volumes:
      - ms2_pgdata:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U ${DB_USER} -d ${DB_NAME}"]
      interval: 5s
      timeout: 5s
      retries: 5

  app:
    image: marianoutec/ms2-api-app:latest
    container_name: ms2-app
    depends_on:
      postgres:
        condition: service_healthy
    ports:
      - "${PORT}:${PORT}"
    env_file:
      - .env
    environment:
      DB_HOST: postgres

  seed-ms2:
    image: marianoutec/ms2-seed:latest
    container_name: ms2-seed
    depends_on:
      postgres:
        condition: service_healthy
    env_file:
      - .env
    profiles:
      - seed

volumes:
  ms2_pgdata:


.env:

PORT=8002
ENV=local

# PostgreSQL 16 temporal en esta misma VM
DB_HOST=postgres
DB_PORT=5432
DB_NAME=vuelos_db
DB_USER=ms2_user
DB_PASSWORD=ms2_pass


(NO OLVIDAR ABRIR EL PUERTO 8002 PARA PÚBLICO (0.0.0.0))


-----------------------------CARGAR DATOS DE PRUEBA (SEED, una sola vez):

Se ejecuta como un servicio aparte (con "profile"), no queda corriendo:

docker compose --profile seed run --rm seed-ms2

Verificar:

docker exec -it ms2-postgres psql -U ms2_user -d vuelos_db -c "
SELECT 'vuelo' AS tabla, COUNT(*) FROM vuelo
UNION ALL SELECT 'asiento', COUNT(*) FROM asiento;
"


-----------------------------PARA LA BD REAL (modifica .env y quita postgres local):

NUEVO .env:

PORT=8002
ENV=local

DB_HOST=IP_PRIVADA_DE_LA_DB
DB_PORT=5432
DB_NAME=vuelos
DB_USER=postgres
DB_PASSWORD=la_contraseña_que_me_pase_Benja


NUEVO docker-compose.yml:

services:
  app:
    image: marianoutec/ms2-api-app:latest
    container_name: ms2-app
    ports:
      - "${PORT}:${PORT}"
    env_file:
      - .env

  seed-ms2:
    image: marianoutec/ms2-seed:latest
    container_name: ms2-seed
    env_file:
      - .env
    profiles:
      - seed


docker compose down -v
docker compose up -d
docker ps
curl http://localhost:8002/actuator/health

Para correr el seed contra la BD real (una sola vez):

docker compose --profile seed run --rm seed-ms2
